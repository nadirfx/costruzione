## 🎯 CAMPAGNA 1: LUXURY LIFESTYLE

### PASSO 1️⃣ - Accedi a Ads Manager
```
👉 https://www.facebook.com/ads/manager
```

### PASSO 2️⃣ - Crea Campagna
```
Click: "+ Create" (tasto blu in alto)
```

### PASSO 3️⃣ - Scegli Obiettivo
```
Objective: LEAD GENERATION
(oppure CONVERSIONS se hai e-commerce)

Campaign Name: "Halo_LuxuryLifestyle_Oct2024"
```
**Click: NEXT**

---

### PASSO 4️⃣ - SETUP AD SET

**AD SET NAME:**
```
LuxuryLifestyle_25-55_IT
```

**DAILY BUDGET:**
```
€12,50
```

**SCHEDULE:**
```
Always Turn On
```

**TARGETING:**
```
Location: Italy 🇮🇹

Age: 25 → 55

Gender: All

Detailed Targeting (aggiungi questi):
  ✓ Luxury Goods
  ✓ Watches & Jewelry
  ✓ Fashion & Style
  ✓ Premium Brands
  ✓ High Income Earners
```

**PLACEMENT:**
```
Automatic Placements ✓
(Meta sceglie per te = migliore)
```

**OPTIMIZATION:**
```
Conversion Event: Lead (or Purchase)
Bid Strategy: Automatic Bidding
```

**Click: NEXT**

---

## 📊 DOPO LANCIO (Daily)

```
Ads Manager → Campaigns

Guarda queste colonne:
  🔴 Amount Spent
  🟡 Results (Leads)
  🟠 Cost Per Result (CPC/CPL)
  🟢 CTR (Click Through Rate)
  🔵 Reach
```

**Target giornaliero:**
- CPL: < €3
- CTR: > 0,8%
- Se pessimo: PAUSE e ottimizza
