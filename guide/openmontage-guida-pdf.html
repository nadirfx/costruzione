Cosa ti serve

Quattro cose sul computer. Le installi una volta sola.

1

Claude Code

Lo strumento di Claude per computer, non l'app di chat. Serve un piano Claude a pagamento.

2

Git e Python 3.10+

Per scaricare il progetto e far girare gli strumenti.

3

Node.js 22 o più recente

Serve per il montaggio. Versioni consigliate: 22.23.4+, 24.22.1+ o 26.12.1+.

4

FFmpeg

Mac: brew install ffmpeg · Linux: sudo apt install ffmpeg · Windows: da ffmpeg.org.

Installazione3 / 5

Pronto in 3 passi

Apri il terminale e copia i comandi, uno alla volta.

1

Scarica e installa

L'ultimo comando installa tutto, voce gratuita compresa.

git clone https://github.com/OpenMontageInc/OpenMontage.git cd OpenMontage make setup
2

Apri Claude Code

Sempre dentro la cartella OpenMontage.

claude
3

Descrivi il video

Anche in italiano. Questo esempio è gratis:

> Fammi un video animato verticale di 45 secondi che spiega perché il cielo è blu, con voce e sottotitoli
Su Windows il comando make spesso manca: sulla pagina GitHub trovi gli stessi passaggi uno per uno.

Come lavora4 / 5

Cosa fa da solo

Dall'idea al video finale, in sei fasi.

1

Ricerca

Da 15 a 25 ricerche sul web prima di scrivere una riga.

2

Script

Ti propone l'idea e scrive il testo.

3

Scene

Progetta ogni scena del video.

4

Immagini e clip

Le crea con l'AI o le prende da archivi gratuiti.

5

Voce narrante

Gratis con Piper, oppure ElevenLabs e altre.

6

Montaggio

Monta tutto con i sottotitoli e ricontrolla il risultato.

Decidi tu: si ferma su proposta, script, scene e materiali e ti chiede se approvi. Puoi dire "più corto", "tono più serio".

Costi e formati5 / 5

Quanto costa

Gratis

Il programma è gratis. Senza abbonamenti: voce Piper, filmati d'archivio (NASA, Wikimedia, Archive.org), sottotitoli e montaggio.

A consumo

Solo se colleghi servizi esterni nel file .env: clip AI (Kling, Veo, Runway), voci ElevenLabs, musica.

Ti avvisa prima

Stima il costo prima di spendere e chiede conferma per le spese sopra 0,50 $.

Tetto massimo

Di base non supera 10 $ in totale. Puoi cambiarlo.
