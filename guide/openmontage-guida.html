Guida · progetto gratuito per Claude Code

Descrivi un video. Claude lo produce.

OpenMontage trasforma Claude Code in uno studio di produzione video. Gli scrivi un'idea: fa le ricerche, scrive lo script, progetta le scene, crea immagini e clip, aggiunge voce e musica e monta tutto con i sottotitoli. E prima di ogni fase importante ti chiede di approvare.

Cosa ti serve

  • Claude Code, lo strumento di Claude per computer (non l'app normale di chat). Serve un piano Claude a pagamento.
  • Git e Python 3.10 o più recente.
  • Node.js 22 o più recente (versioni aggiornate: 22.23.4+, 24.22.1+ o 26.12.1+).
  • FFmpeg: su Mac brew install ffmpeg, su Linux sudo apt install ffmpeg, su Windows da ffmpeg.org.

Non serve una scheda grafica: serve solo se vuoi generare clip AI gratis sul tuo computer.

Installazione in 3 passi

  1. Scarica il progetto

    Apri il terminale e copia questi comandi. Il terzo installa tutto quello che serve, voce gratuita compresa.

    git clone https://github.com/OpenMontageInc/OpenMontage.git
cd OpenMontage
make setup

    Se il comando make non c'è (succede spesso su Windows), sulla pagina GitHub trovi gli stessi passaggi uno per uno.

  2. Apri Claude Code nella cartella

    Sempre dentro la cartella OpenMontage, così Claude legge le istruzioni dello studio.

    claude

  3. Descrivi il video

    Scrivi cosa vuoi, anche in italiano. Un esempio che funziona senza nessuna chiave a pagamento:

    Fammi un video animato verticale di 45 secondi che spiega perché il cielo è blu, con voce e sottotitoli

Cosa succede dopo

  1. Ricerca

    Prima di scrivere fa da 15 a 25 ricerche sul web: YouTube, Reddit, notizie, fonti accademiche.

  2. Proposta e script

    Ti propone l'idea e scrive lo script. Si ferma e ti chiede: approvi?

  3. Piano delle scene e materiali

    Progetta ogni scena, poi crea o cerca immagini, clip, voce e musica. Ti mostra un foglio con le anteprime prima di andare avanti.

  4. Montaggio

    Monta il video con i sottotitoli e lo ricontrolla da solo dopo il render.

Consiglio: a ogni pausa puoi dire cosa cambiare con parole tue: "più corto", "tono più serio", "cambia la voce". Lui riparte da lì.

Quanto costa

Gratis

Senza chiavi API: voce Piper gratuita, filmati d'archivio (Archive.org, NASA, Wikimedia), sottotitoli e montaggio.

Con le chiavi API

Le aggiungi nel file .env, tutte facoltative: clip AI (Kling, Veo, Runway…), voci ElevenLabs, musica. Si pagano a consumo.
