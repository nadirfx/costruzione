Descrivi un gioco. Claude lo costruisce.

Claude Code Game Studios trasforma Claude Code in uno studio di videogiochi. Gli descrivi un'idea: ti fa qualche domanda, scrive il progetto in una pagina e costruisce un gioco che apri nel browser con un doppio clic.

Cosa ti serve

  • Claude Code, lo strumento di Claude per computer (non l'app normale di chat). Serve un piano Claude a pagamento.
  • Git e Python 3 installati sul computer.
  • Chrome, Edge o Chromium: la skill ci prova da sola il gioco prima di dartelo.
  • Consigliato: Node.js, per far crescere il gioco in un progetto vero.

Su Windows usa il terminale Git Bash, che arriva insieme a Git per Windows.

Installazione in 3 passi

  1. Scarica la skill

    Apri il terminale e copia questo comando. Crea una cartella mio-gioco con tutto lo studio dentro.

    git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git mio-gioco

  2. Entra nella cartella e apri Claude Code

    Aprilo proprio in questa cartella, non in una sottocartella: altrimenti le regole dello studio non si attivano.

    cd mio-gioco
claude

  3. Descrivi il tuo gioco

    Scrivi /prototype seguito dalla tua idea. Se non sai da dove partire, scrivi /start e ti guida lui.

    /prototype un gioco di pesca dove i pesci rari abboccano solo al tramonto

Cosa succede dopo il comando

  1. Qualche domanda

    Un giro solo: come si gioca, che sensazione deve dare, lo stile, la difficoltà, l'obiettivo. Ogni domanda ha una risposta già pronta, quindi puoi anche dire "scegli tu".

  2. Il progetto in una pagina

    Scrive il brief del gioco con le tue parole, l'aspetto, il primo minuto di gioco e cosa lasciare per dopo. Lo leggi e dici "costruiscilo", oppure cambi qualcosa.

  3. Il gioco nel browser

    Costruisce il gioco nella cartella prototypes: si apre con un doppio clic.

  4. Il controllo prima di consegnartelo

    Lo prova da solo in un browser, sistema testi fuori schermo o schermate bloccate e ti dice cosa funziona, cosa no e cosa ha dovuto indovinare.

Consiglio: giocalo, poi chiedigli le modifiche a parole: "rendilo più difficile", "aggiungi un boss". Ogni modifica che accetti diventa un punto a cui puoi tornare.

Quando il gioco ti piace

Regola tutto

Chiedigli un pannello con un cursore per ogni valore: velocità, salto, nemici.

Condividilo

Ti prepara una copia pulita, pronta per itch.io o da mandare come link.

Fallo crescere

Lo trasforma in un progetto web vero e aggiunge una funzione per volta, provata e salvata.

Finiscilo

Con /cut ti propone cosa tagliare e cosa rifinire per arrivare alla fine.

Com'è fatta dentro

Nella modalità studio, pensata per i progetti grandi, lavorano 49 agenti su tre livelli, come in uno studio vero.

DirettoriDirettore creativo, direttore tecnico, produttore.
Capi repartoGame design, programmazione, arte, audio, narrativa, test, rilascio, localizzazione.
SpecialistiChi scrive la storia, chi disegna i livelli, chi bilancia l'economia del gioco, chi programma l'intelligenza dei nemici e molti altri.

Funziona nel browser e anche con Godot, Unity e Unreal.
