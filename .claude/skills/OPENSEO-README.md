# OpenSEO skills

Skills copied from https://github.com/every-app/open-seo (plugins/openseo/skills, MIT License, © Ben Senescu).

They need the OpenSEO MCP server (`https://app.openseo.so/mcp`, or a self-hosted instance)
to be connected. Setup: https://openseo.so/docs/mcp

Costs: SEO data comes from DataForSEO and is paid per use (hosted OpenSEO adds a markup;
self-hosting means paying DataForSEO directly). Search Console reads and project setup are free.
Always tell the user the cost before running paid research.
